Font Reference

Two font families are available. The 5×7 bitmap font is pixel-scaled; the FreeMono fonts are proportional-quality bitmap fonts (Adafruit GFX format, MIT license) stored in flash with zero heap cost.

fontFamilyGlyph size (px)Line height (yAdvance)Min y spacing between lines
15×7 bitmap, 1× scale5×78 px≥ 8 px
25×7 bitmap, 2× scale10×1416 px≥ 16 px
35×7 bitmap, 3× scale15×2124 px≥ 24 px
45×7 bitmap, 4× scale20×2832 px≥ 32 px
5FreeMono 9ptup to 9×1118 px≥ 18 px
6FreeMono 12ptup to 11×1524 px≥ 24 px
7FreeMono 18ptup to 16×2235 px≥ 35 px

Y spacing note: The y property is the top of the character cell for all font indices. For fonts 5–7 (FreeMono), the cell height equals the yAdvance value shown above. If consecutive label nodes have y values closer together than the minimum spacing, glyphs will overlap. The existing 5×7 DSL files use 12 px spacing — this is fine for font: 1 but too tight for any FreeMono font; you must re-space those nodes when switching fonts.

All FreeMono fonts are monospace, so column-aligned templates (e.g. "80/40m {{hf_80_day}} {{hf_80_night}}") continue to align correctly.
